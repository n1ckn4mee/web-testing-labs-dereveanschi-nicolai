# Local Study Shop 2.0

Учебный локальный проект Dereveanschi Nicolai. Нужны Python 3.12+, Chrome. Создать venv, установить requirements.txt. Задать вымышленный LAB_TEST_PASSWORD одинаковым для сервера и тестов, запустить python app/server.py, затем python -m pytest. В CI headless включается переменной CI.

Настоящий GitHub Actions запуск [#1](https://github.com/n1ckn4mee/web-testing-labs-dereveanschi-nicolai/actions/runs/40111799087) успешно завершён 24.10.2026. Артефакт rapoarte содержит HTML и JUnit XML. Этот коммит проверяет повторный автоматический запуск по push. Локальная среда Python 3.12.14; облачная 3.12.15.
